## 3. WAF custom taisyklės (Free — 5 taisyklės)
1. **Skip** (aukščiau) — pirmoji.
2. **Managed Challenge**: `http.request.uri.query matches "(^|&)(yith_wcan|filter_[a-z0-9_-]+|query_type_[a-z0-9_-]+|add-to-cart)=" and not http.cookie contains "ps_js=1" and not http.cookie contains "wordpress_logged_in_"` — botų banga.
3. **Managed Challenge**: `http.request.uri.path contains "/page/" and not http.cookie contains "ps_js=1"` — jei botai persijungs į puslapiavimą (kol kas OFF, paruošta).
4. **Block**: `http.request.uri.path eq "/xmlrpc.php" or http.request.uri.path contains "/wp-login.php" and not ip.geoip.country in {"LT" "LV" "EE" "PL"}` — (S1678 saugumas; Ingos/Raimio prisijungimai iš LT).
5. Rezervas.
**Rate limiting (1 nemokama)**: `http.request.uri.path contains "/kategorija/" or contains "/gamintojas/" or contains "/parduotuve/" or http.request.uri.query contains "s="` → > 60 užkl./10 s iš IP → block 10 min. (Free: tik IP raktas, 10 s langas.)
